Perpetual Documentation

Perpetual is a self-generalizing gradient boosting machine (GBM) implemented in Rust with native Python and R bindings. Unlike traditional gradient boosting libraries (such as LightGBM, XGBoost, and CatBoost) that require extensive hyperparameter optimization across learning rate, tree depth, and regularization parameters, PerpetualBooster automatically controls step size and node-split generalization via a single intuitive budget parameter.

Key Capabilities

  • Hyperparameter-Free Learning: Achieves state-of-the-art accuracy in a single training run via a simple budget parameter, eliminating multi-trial hyperparameter tuning (see How PerpetualBooster Works).

  • High-Performance Rust Core: Parallelized histogram construction, split finding, and inference powered by Rust and Rayon, with zero-copy support for Polars/Arrow columnar data and native Python & R bindings.

  • Comprehensive Objectives: Supports Binary & Multi-class Classification, Regression (Squared, Absolute, Huber, Quantile, Poisson, Gamma, Tweedie, MAPE), and Learning-to-Rank (ListNet), as well as custom user-defined objectives.

  • Advanced Tree Features: Natively handles categorical variables, learnable missing value branches, monotonic constraints, and feature interaction constraints.

  • Continual Learning: Built-in warm-start continual learning (reset=False) that updates models incrementally as new batches arrive, reducing cumulative training complexity from quadratic \(O(n^2)\) to linear \(O(n)\) without sacrificing accuracy (see Continual Learning and Further Speed-Up with Continual Learning).

  • Native Calibration & Prediction Intervals: Predict calibrated probabilities and rigorous prediction intervals (Conformalized Quantile Regression, GRP, MinMax, WeightVariance) that achieve 35% narrower intervals than MAPIE at matching coverage (see Calibration and Uncertainty Quantification and Better Prediction Intervals with Perpetual Learning).

  • Robust Drift Monitoring: Monitor both data drift and concept drift directly from model tree topology without requiring ground-truth labels or retraining (see Drift Detection).

  • Built-in Causal ML: Out-of-the-box Uplift Modeling, Meta-Learners (S-, T-, X-, R-, DR-Learner), Double Machine Learning (DML), and Structural Policy Learning (see Causal ML).

  • Explainability & Interoperability: Compute feature importances, partial dependence plots, and exact TreeSHAP values (Explainability), and export models to industry-standard XGBoost or ONNX formats (Model IO & Export).
